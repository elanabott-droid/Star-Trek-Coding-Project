# Star-Trek-Coding-Project
Star Trek: Through the Ages is aimed at bringing the theme song from the 1966 Star Trek series to life in a way that accurately reflects the original song while still being viable as a coded piece of music. This was done to pay homage to the series that brought so many joy when they were young, while also giving a sense of modernity. The project consists of 6 piano cells, each with their own parts that allign. These include the Right Hand, the Right Hand Extra, the Left hand, the Left hand Extra, the Supporting Chords and the Supporting Chords Extra.

## General Information
As a first-time coder, I created Star Trek: The Final Frontier to explore how coding can be used as a creative tool for artistic expression. Inspired by Star Trek, my favourite show growing up, this project allowed me to combine my love of music and the series with my curiosity about programming. It showed me that code can be both logical and expressive, and became a way to learn through experimentation, creativity, and problem-solving while paying tribute to something personally meaningful to me.

## Set Up
To setup 'Star Trek: The Final Frontier' first open .JSON file in this hub, and download the it file. Next sign into TunePad, go to 'My Tunes', select import and import the .JSON file. Now press start!
